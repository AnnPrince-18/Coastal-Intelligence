# Coastal-Intelligence
##Project overview
Coastal & Beach Safety Intelligence is a data analytics project developed using Microsoft Power BI to explore coastal conditions, beach information, weather patterns, tourism and water quality across Kerala.

The project integrates multiple datasets to transform raw data into meaningful insights through interactive dashboards and visual reports. It aims to support better understanding of coastal environments, identify important patterns and provide an informative overview of beach and water conditions

##🎯 Project Objectives
- Analyse coastal and beach-related information across Kerala.
- Understand weather patterns and environmental conditions.
- Monitor water quality indicators and their variations.
- Explore beach locations and their geographical distribution.
- Analyse tourism-related trends and visitor patterns.
- Present meaningful insights through interactive visualizations.

##🗂️ Datasets Used
The project combines four main datasets:

1. Beach Information

- Beach names and locations
- District information
- Geographical coordinates
- Beach categories

2. Weather Data

- Temperature
- Rainfall
- Wind conditions
- Date and location details
  
3. Coastal & Water Quality Data

- Water temperature
- pH levels
- Dissolved Oxygen (DO)
- Biological Oxygen Demand (BOD)

4. Beach & Safety Information

- Beach locations
- District details
- Safety categories
- Geographical information

##📊 Dashboard Features
- Coastal Overview: Provides an overall view of coastal locations and key indicators.
- Tourism & Weather Analysis: Explores tourism patterns alongside weather conditions.
- Water Quality Intelligence: Analyses water quality indicators, including pH, dissolved oxygen and BOD.
- Beach Explorer: Displays beach locations and geographical information through interactive visualizations.

  
##🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning and Transformation
- Data Modelling
- Data Visualization

##⚙️ Project Workflow
1. Dataset collection and preparation.
2. Data cleaning and transformation using Power Query.
3. Data modelling and relationship creation.
4. Development of calculated measures using DAX.
5. Creation of interactive charts, maps and KPIs.
6. Dashboard design and visualization

##💡 Key Learning Outcomes

- Practical experience in data analytics and business intelligence.
- Understanding data cleaning and transformation techniques.
- Working with multiple datasets and data relationships.
- Developing interactive dashboards using Power BI.
- Presenting complex information through meaningful visualizations

##📌 Project Outcome

Developed an interactive Power BI dashboard that brings together coastal, weather, tourism and water quality information to provide a consolidated view of Kerala's coastal environment
